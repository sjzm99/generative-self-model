表针层次中关于幻觉判断的概念混淆.md

    经过一段时间的持续思考，终于意识到在自我问题中的中枢方法，即取消认识论的上帝视角。
    
    和之前相比，之前会把整个理论构建在关系本体论和意义发生学之上，那样论证链条会比较长，而现在则把整个自我的理论构建在一个自然化的认识论上。
    
    这个自然会认识论其实是关系本体论层面的一个基本内容之一，但以这种方式阐述，我们彻底的避开了困难问题。
    
    这是一个很好的进展，慢慢习惯用比较简短的逻辑链条去把一个独立的问题讲清楚。
